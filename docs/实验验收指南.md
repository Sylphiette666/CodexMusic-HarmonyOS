## 准备

1. 在 DevEco Studio 打开工程根目录，完成 SDK、依赖和自动签名配置。
2. 运行 `scripts/build.ps1` 或使用 DevEco Studio 构建，保存完整日志。本机模拟器已允许未签名 HAP 安装；真机先完成签名，其他模拟器按各自安装策略处理。
3. 准备一首有标题/歌手/专辑标签的合法音频；可带内嵌封面。另备一首无标签音频、一个空或损坏的音频文件。
4. 为其中一首音频准备同名 UTF-8 `.lrc`；另备增强 LRC 验证字级时间。素材须有权使用，不要求下载商业歌曲。
5. 开启设备声音。语音验收使用有真实麦克风和可用 Core Speech 服务的设备；若模拟器缺少相关能力，记录环境限制。

仅检查基本播放时可直接使用内置的三首 30 秒原创器乐。要验收“导入”与“扫描”，必须另外从系统选择器导入文件；内置原始资源不在应用导入目录内。

## 歌词验收样例

将下面内容保存为 UTF-8 `sample.lrc`，在播放页选择“导入 LRC”。示例只有教学配文，并不表示任何歌曲的真实演唱时间。

```text
[ti:实验时间轴]
[ar:实验配文]
[offset:0]
[00:00.00]普通行级时间演示
[00:05.00]<00:05.00>听<00:05.80>见<00:06.60>音<00:07.40>乐<00:08.20>
[00:10.00]跳转进度后仍应正确定位
[00:20.00]接近结尾时观察下一首
```

记录普通行和增强行各自的显示标签。普通 LRC 的字符动画只是估算；增强 LRC 是否贴合真实发音，应使用有实际字时间标记的演唱素材另行检验。
