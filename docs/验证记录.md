## 已修复并回归的问题

- API 24 phone 的 `canIUse(FolderSelection)` 返回 true，但系统忽略 FOLDER 选项。早期读取到的“已关联 4 行歌词”属于旧 Notice，已排除为无效证据。修复为 `deviceInfo.deviceType === '2in1'` 与 syscap 双重检查；新增两个 mock 回归场景，最终模拟器现已明确显示目录限制提示。
- AVSession 暂停时发送 `speed=0` 导致 401，修正为合法 `speed=1`，由播放状态字段表达暂停。最终版暂停、seek 和后台任务回归通过，无该 401。
- AVPlayer 的 `stateChange` 统一为一个原生监听器，避免多个原生监听注册相互干扰；状态等待与界面状态更新统一分发。服务 mock 与最终原生播放控制回归通过。
